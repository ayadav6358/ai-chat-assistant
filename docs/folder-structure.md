# Folder Structure

## Root
- client/: React frontend application
- server/: Node.js/Express backend application
- docs/: architecture, roadmap, and design notes
- scripts/: repository automation scripts

## Client
- src/components/: reusable UI building blocks
- src/pages/: route-level screens
- src/services/: API clients and integration logic
- src/hooks/: shared hooks
- src/types/: shared TypeScript types
- src/utils/: helper functions and constants

## Server
- src/routes/: HTTP route definitions
- src/controllers/: request/response orchestration
- src/services/: business logic and integrations
- src/repositories/: persistence abstraction
- src/middleware/: auth, errors, validation
- src/config/: configuration and environment setup
- src/types/: shared server-side types
- src/utils/: helper utilities
